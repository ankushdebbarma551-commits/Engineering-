# Engineering Simulator

A Kotlin-based Android application for simulating engineering fault detection and management.

## Features
- Fault generation and detection
- Interactive UI with buttons for various tools
- XP tracking system
- Material Design components

## Technology Stack
- **Language**: Kotlin
- **Platform**: Android (API 24+)
- **Build System**: Gradle
- **Compile SDK**: 34

## Project Structure
```
app/
├── src/main/
│   ├── java/com/example/engineeringsimulator/
│   │   ├── MainActivity.kt
│   │   └── FaultManager.kt
│   ├── res/
│   │   ├── layout/
│   │   ├── values/
│   │   └── mipmap/
│   └── AndroidManifest.xml
└── build.gradle
```

## Dependencies
- AndroidX Core KTX
- AndroidX AppCompat
- Material Components
- ConstraintLayout

## Getting Started
1. Clone the repository
2. Open in Android Studio
3. Sync Gradle files
4. Run on an emulator or physical device
